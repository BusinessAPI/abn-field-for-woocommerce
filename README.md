# ABN Field for WooCommerce

Adds an Australian Business Number field to the WooCommerce billing address, checked with the official ABN checksum.

- Classic checkout, Checkout block and My Account
- Shown only when the billing country is Australia
- Required: no, yes, or only when a company name is entered
- Saved as `51824753556` or `51 824 753 556`
- Shown on the admin order screen, order emails, thank-you page and My Account
- No external requests, no account

Install from [WordPress.org](https://wordpress.org/plugins/abn-field-for-woocommerce/) (pending review). Requires WordPress 6.5+, PHP 8.1+, WooCommerce 9.9+.
